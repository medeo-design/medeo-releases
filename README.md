# Medeo releases

Installers and update files for the Medeo desktop app.

Download the latest version from [Releases](https://github.com/medeo-design/medeo-releases/releases/latest).

| Platform | File |
| --- | --- |
| macOS (Apple silicon and Intel) | `MEDEO-mac-universal.dmg` or `.pkg` |
| Windows (x64) | `MEDEO-windows-x64.exe` |
| Linux (x64 / arm64) | `.AppImage`, `.deb` or `.rpm` |

Installed apps update themselves from this page.
